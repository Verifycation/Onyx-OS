# Changelog

## v1.1.0

### Adicionado
- Interface de terminal com menu principal e comandos CLI.
- Modo Game Mode com scanner de jogos e boas práticas de otimização.
- Modo Admin Mode com comandos de limpeza, otimização e diagnóstico.
- King Mode com funcionalidades adicionais.
- Manual de códigos integrado no sistema.
- Configuração persistente em `config.json`.

### Melhorado
- Organização do projecto para facilitar a manutenção e publicação.
- Preparação para distribuição via instalador Electron Builder.

### Notas
- Esta versão foi compilada para Windows e disponibilizada em `dist/`.
- O instalador cria atalhos e permite arranque a partir do menu Iniciar e da área de trabalho.
